# ON:DA.LAB AI 협업 투명성 표기 정책

## 목적

ON:DA.LAB은 AI를 사용했다는 사실만 표시하지 않고, **어디까지 AI가 참여했고 누가 최종 책임을 지는지**를 이용자가 확인할 수 있도록 공개한다.

이 정책은 ON:DA.LAB이 서비스하거나 공개하는 모든 웹페이지, 디지털 콘텐츠, 보고서와 자동화 산출물에 적용한다.

## 필수 표기 항목

| 항목 | 작성 기준 | 작성 예시 |
|---|---|---|
| AI 사용 범위 | AI가 실제로 수행하거나 보조한 작업만 구체적으로 작성 | 자료 구조화·초안 작성·이미지 생성·웹 구현 |
| 원본 출처 | 원문, 데이터, 이미지, 요구사항의 출처를 구분 | 김선미 대표 제공 자료 및 직접 작성 콘텐츠 |
| 사람의 검토자 | 사실 확인·수정·최종 판단·공개 승인 담당자 | 김선미 대표 최종 검토·수정 |
| 공개 표시 | 산출물의 AI 관여와 공개 상태를 함께 표시 | AI 보조 제작물·Human Reviewed·공개 승인 |

## 권장 UI

페이지에는 다음 네 개의 요약 배지를 먼저 노출한다.

- `AI 보조` 또는 `AI 생성 포함`
- `원본: 직접 제공` 등 출처 요약
- `Human Reviewed`
- `공개 가능`, `공개 승인`, `내부용` 중 실제 상태

배지를 선택하면 필수 표기 항목 네 개와 다음 책임 문구를 확인할 수 있어야 한다.

> 최종 판단과 공개 책임은 사람에게 있습니다. AI 출력은 검토 없이 사실이나 결과로 사용하지 않습니다.

## 공개 단계

| 표시 | 의미 |
|---|---|
| 내부용 | 검토 또는 개발 중이며 외부 공개를 승인하지 않은 자료 |
| AI 보조 제작물 | 사람이 원본과 방향을 제공하고 AI가 일부 제작을 보조한 자료 |
| AI 생성 포함 | 이미지·음성·영상·문장 등 공개 결과에 AI 생성 요소가 포함된 자료 |
| Human Reviewed | 지정한 사람이 사실·표현·저작권 위험을 검토한 자료 |
| 공개 승인 | 책임자가 외부 공개를 최종 승인한 자료 |

## 금지 사항

- 실제 사용하지 않은 AI 작업을 사용한 것으로 표시하지 않는다.
- 고객·기관·제3자 제공 자료를 `직접 작성`으로 표시하지 않는다.
- 검토자가 확인하지 않은 산출물에 `Human Reviewed`를 표시하지 않는다.
- AI에게 최종 결정권·책임·공개 승인 주체가 있는 것처럼 표현하지 않는다.
- 출처와 공개 권한을 확인할 수 없는 자료를 공개 가능으로 표시하지 않는다.
